# Phase 5 — UI Design Contract

## Admin Dashboard & CMS Design System
- **Shell:** Dark/neutral sidebar navigation (`/admin`, `/admin/dishes`, `/admin/categories`, `/admin/fortunes`, `/admin/settings`), top header with admin avatar and logout button.
- **Login Screen:** Centered auth card with email/password inputs, error alerts, and remember session cookie.
- **Data Tables:** Clean borders, sticky header, search filtering, inline action buttons (Edit, Delete, Toggle Active).
- **Modals & Forms:** Two-column dialog for dish editing with image preview, price input in VND, and category selector.
