# Plan 01-02: Drizzle ORM Schema Definition for Turso

## Goal
Set up Drizzle ORM with libSQL/Turso driver, define schema tables for dishes, categories, fortunes, site settings, and the atomic global spin counter, supporting dual-mode local and cloud execution.

## Requirements Addressed
- **DATA-02**: Drizzle ORM schema created for dishes, categories, fortunes, site settings, and counters

## Tasks

<task id="01-02-01">
### Task 1: Install Drizzle ORM and Turso client
Add dependencies:
- `drizzle-orm@0.45.2`, `@libsql/client@0.18.0`
- Dev dependencies: `drizzle-kit@0.31.10`
- Add scripts in package.json: `"db:generate": "drizzle-kit generate"`, `"db:push": "drizzle-kit push"`, `"db:studio": "drizzle-kit studio"`.
- Create `drizzle.config.ts` targeting `libsql` dialect.
</task>

<task id="01-02-02">
### Task 2: Define Drizzle Schema
Create `src/db/schema.ts` defining:
- `categories`: `id` (text pk), `name` (text), `tab` (text: mon_chinh / do_uong / an_vat / mon_nhau), `sort_order` (integer default 0).
- `dishes`: `id` (text pk), `name` (text), `subtitle` (text), `price` (integer), `categoryId` (text references categories.id), `rarity` (text: QUOC_DAN, HIEM, CUC_PHAM, TOI_MAT, DAC_BIET), `imageUrl` (text), `dietTags` (text JSON string), `isActive` (integer default 1), `createdAt` (integer timestamp).
- `fortunes`: `id` (text pk), `text` (text), `advice` (text), `luckyDishId` (text), `isActive` (integer default 1).
- `siteSettings`: `key` (text pk), `value` (text), `updatedAt` (integer timestamp).
- `counters`: `key` (text pk), `value` (integer default 0).
</task>

<task id="01-02-03">
### Task 3: Instantiate Database Client with Dual-Mode Fallback
Create `src/db/index.ts`:
- Check `process.env.TURSO_DATABASE_URL` and `process.env.TURSO_AUTH_TOKEN`.
- If unset, connect to local file: `file:local.db`.
- If set, connect to Turso cloud URL using HTTPS.
- Export typed `db` instance.
</task>

## Verification
- Run `pnpm exec drizzle-kit push` to verify local schema generation against `file:local.db`.
