# Plan 01-01: Project Scaffolding & Public Layout Shell

## Goal
Scaffold the Next.js 16 App Router application with Tailwind CSS v4, Be Vietnam Pro typography, and the clean minimal public layout shell with proper attribution.

## Requirements Addressed
- **DATA-03**: Typography renders all Vietnamese diacritics cleanly with zero clipping using Be Vietnam Pro
- **EXTR-05**: Public footer prominently displays data source and inspiration credit to `truanayangi.com`

## Tasks

<task id="01-01-01">
### Task 1: Initialize package.json and core dependencies
Create package.json and install:
- `next@16.3.5`, `react@19.3.0`, `react-dom@19.3.0`
- `tailwindcss@4.3.3`, `@tailwindcss/postcss@4.3.3`
- `typescript@5.9.3`, `@types/node`, `@types/react`, `@types/react-dom`
- `lucide-react`, `clsx`, `tailwind-merge`
- Setup tsconfig.json and next.config.ts with path alias `@/*` mapping to `./src/*`.
</task>

<task id="01-01-02">
### Task 2: Configure Tailwind CSS v4 and styling
- Create `postcss.config.mjs` with `@tailwindcss/postcss`.
- Configure `src/app/globals.css` with `@import "tailwindcss";` and `@theme` tokens matching `01-UI-SPEC.md`.
- Provide `src/lib/utils.ts` with `cn()` class merger.
</task>

<task id="01-01-03">
### Task 3: Build Root Layout and Public Shell
- In `src/app/layout.tsx`, load `Be_Vietnam_Pro` from `next/font/google` with `subsets: ["vietnamese", "latin"]` and weights `["400", "500", "600", "700", "800"]`.
- Create `src/components/public/Header.tsx` with text logo "Trưa Nay Ăn Gì", subtle badge, and link to `/dishes`.
- Create `src/components/public/Footer.tsx` with attribution link to `truanayangi.com`, GitHub repo link, and legal links.
- Create `src/app/(public)/layout.tsx` combining Header, centered `max-w-4xl` container, and Footer.
- Create placeholder `src/app/(public)/page.tsx` with welcome hero ready for Phase 2 spin engine.
</task>

## Verification
- Run `pnpm build` or `pnpm exec tsc --noEmit` to verify type checking passes.
- Check that `next/font/google` compiles without network requests at runtime.
