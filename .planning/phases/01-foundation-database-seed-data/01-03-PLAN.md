# Plan 01-03: Dataset Porting and Database Seeder

## Goal
Extract and bundle the complete Vietnamese dish catalog and taxonomy from `truanayangi-com/truanayangi`, implement a runnable database seeder, and verify clean database hydration.

## Requirements Addressed
- **DATA-01**: Initial dish dataset ported from original `truanayangi-com/truanayangi` repository and seeded into Turso DB

## Tasks

<task id="01-03-01">
### Task 1: Create Seed Data Snapshot
Create `src/db/seed-data.ts`:
- Port categories from original repo: Bún/phở/mì, Cơm & xôi, Bánh mì & cuốn, Pizza & pasta, Nướng & chiên, Salad & món nhẹ, Chay, Đồ uống, Ăn vặt.
- Port 60+ dishes with accurate Vietnamese names, descriptions, standard prices in VND, categories, and rarity ratings (`QUOC_DAN`, `HIEM`, `CUC_PHAM`, `TOI_MAT`, `DAC_BIET`).
- Define initial site settings (default picker mode: `roulette`, initial homepage copy).
- Initialize `global_spins` counter at 0.
- Define a starter pack of 20+ Quẻ trưa lunch fortunes with witty Vietnamese advice.
</task>

<task id="01-03-02">
### Task 2: Implement Database Seeder Script
Create `scripts/seed.ts`:
- Add `tsx` devDependency.
- Add script `"db:seed": "tsx scripts/seed.ts"` to `package.json`.
- Script truncates/upserts categories, dishes, fortunes, siteSettings, and initial counter value.
- Log summary statistics (count of dishes, categories, fortunes inserted).
</task>

<task id="01-03-03">
### Task 3: Execute Seed and Verify Database State
- Run `pnpm run db:push` then `pnpm run db:seed`.
- Verify rows exist in local SQLite or Turso DB.
- Create a lightweight verification test `scripts/verify-db.ts` to assert row counts > 0.
</task>

## Verification
- Run `pnpm run db:seed` and verify console outputs successful insertion of dishes and categories.
- Run `pnpm exec tsx scripts/verify-db.ts` to assert all tables have data.
